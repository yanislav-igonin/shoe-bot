# xAI SDK Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run shoe-bot on Node.js 22 and route every xAI text and image API
call through the latest official xAI provider for AI SDK.

**Architecture:** `src/lib/ai.ts` owns the configured provider,
`src/lib/prompt.ts` owns text-message conversion and completion behavior, and
`src/lib/imageGeneration.ts` normalizes provider-specific image outputs.
Controllers keep their existing flow and only accept either URL-backed or
byte-backed image input.

**Tech Stack:** Node.js 22.23.1, TypeScript, AI SDK 7.0.37,
`@ai-sdk/xai` 4.0.18, grammY, node:test.

## Global Constraints

- `package.json#engines.node` is `22.x`.
- `package.json#volta.node` is `22.23.1`.
- Nixpacks reads Node.js 22 from `engines`; no duplicate Nixpacks config.
- Keep the `openai` dependency and its real OpenAI call.
- Do not modify any file under `prisma/`.
- Preserve prompts, model IDs, fallback behavior, and TogetherAI behavior.
